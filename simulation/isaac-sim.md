# Isaac Sim and Isaac Lab

## Isaac Sim

**Isaac Sim** is NVIDIA's robotics simulator, built on NVIDIA Omniverse. It provides physics simulation and photorealistic rendering for designing, testing, and training robots.

- [Isaac Sim (NVIDIA Developer)](https://developer.nvidia.com/isaac/sim)
- [Isaac Sim documentation](https://docs.isaacsim.omniverse.nvidia.com/)
- [Isaac Sim on GitHub](https://github.com/isaac-sim/IsaacSim)

## Isaac Lab

**Isaac Lab** is an open-source framework for robot learning, built on top of Isaac Sim. It provides the tools to set up robot environments and train policies, for example with reinforcement learning.

- [Isaac Lab documentation](https://isaac-sim.github.io/IsaacLab/main/index.html)
- [Isaac Lab on GitHub](https://github.com/isaac-sim/IsaacLab)

{: .note }
Berkeley Humanoid Lite's code is organized following the Isaac Lab conventions. See the [Berkeley Humanoid Lite repository](https://github.com/HybridRobotics/Berkeley-Humanoid-Lite) for an example.

{: .important }
Isaac Sim needs a capable NVIDIA GPU. Check the system requirements in the Isaac Sim documentation before installing.
