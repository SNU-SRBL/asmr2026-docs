# Berkeley Humanoid Lite

The robot built in this course is a **modified bipedal version of Berkeley Humanoid Lite**, an open-source humanoid robot project from UC Berkeley's Hybrid Robotics group.

## Official resources

- [Project website](https://lite.berkeley-humanoid.org/)
- [Documentation](https://berkeley-humanoid-lite.gitbook.io/docs)
- [GitHub repository](https://github.com/HybridRobotics/Berkeley-Humanoid-Lite)

{: .note }
The upstream project is a reference. Because the course robot is a modified version, follow the guides on this site wherever the course setup differs from upstream, for example in parts, CAD, or software versions.
